# Política de Privacidade — Nosso Evento

Última atualização: 3 de setembro de 2026.

O aplicativo Nosso Evento foi desenvolvido para auxiliar na organização de orçamento, compras e tarefas relacionadas a eventos.

## Dados armazenados
O aplicativo permite que o utilizador registe valores de orçamento, despesas, entradas e saídas do caixa, itens de compra e tarefas. Na versão atual, esses dados ficam armazenados localmente no dispositivo.

## Dados que não recolhemos
O aplicativo não recolhe dados bancários, dados de cartão, localização, contactos, fotografias, identificadores de publicidade ou informações de saúde. Não utilizamos ferramentas de rastreamento ou publicidade.

## Partilha de dados
A versão atual não envia os dados inseridos para servidores externos e não vende nem partilha dados pessoais com terceiros.

## Eliminação dos dados
Os dados podem ser removidos eliminando os registos dentro do aplicativo quando essa função estiver disponível ou removendo o aplicativo do dispositivo, o que elimina o armazenamento local associado conforme as regras do sistema operativo.

## Alterações
Esta política poderá ser atualizada caso sejam adicionadas funcionalidades como sincronização em nuvem, contas de utilizador ou partilha entre participantes. A política deverá ser revista antes de publicar uma versão com essas funcionalidades.

## Contacto
Antes da publicação na App Store, substituir esta secção por um endereço de contacto válido do responsável pelo aplicativo.
